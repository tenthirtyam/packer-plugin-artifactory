# Support

This plugin is supported by the project maintainers and the plugin community.

## Reporting Issues

Before opening an issue:

1. Search [existing issues][gh-issues] (open and recently closed) to avoid
   duplicates.
2. Include a reproducible test case or clear steps.
3. Note any relevant modifications and unusual environment details.

You can also start a [discussion][discussions] to ask questions or share ideas.

[gh-issues]: https://github.com/tenthirtyam/packer-plugin-artifactory/issues
[discussions]: https://github.com/tenthirtyam/packer-plugin-artifactory/discussions
