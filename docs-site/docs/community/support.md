# Support

This plugin is supported by the project maintainers and the plugin community.

## Reporting

Please use [GitHub Discussions][discussions] for triage, ideas, and general
project discussion.

GitHub Issues are reserved for maintainer-tracked work items. Discussions that
turn into confirmed issues or accepted ideas will have a linked issue created by
a maintainer.

Before opening a discussion:

1. Search [existing discussions][discussions] (open and recently closed) to
   avoid duplicates.
2. Include a reproducible test case or clear steps when reporting a problem.
3. Note any relevant modifications and unusual environment details.

[discussions]: https://github.com/tenthirtyam/packer-plugin-artifactory/discussions
